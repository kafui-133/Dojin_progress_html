# 依頼: 進捗ブースターの読み上げ音声を、この PC の音声合成（drama3-small）で作る

あなたはこの PC で動いている Claude Code です。
このリポジトリ（進捗ブースター）は、マンガ・イラストを描いているときに「神作画！」「ZONE突入！！」のようなカットインを声で読み上げます。
その声を、この PC に入っている音声合成モデル **drama3-small** で作り、アプリに読み込める音声ファイルにしてください。

## 入力

- `voice-pack/lines.json`: 作るセリフの一覧と、作ってほしいファイル名
  - `roles`: 6つの役（かわいい役・渋い役・男性・お姉さん・小学生の女の子・小学生の男の子）の声のイメージ
  - `voices`: 作る声の一覧（`cute1` など。役ごとに声色違いが複数ある）
  - `moods`: 演技の方向（`hype` = カットインの叫び、`calm` = 落ち着いたお知らせ）
  - `lines[]`: 各セリフ
    - `readings.<役>`: **この文字を読ませる**（役ごとに語尾が少し違う）
    - `text`: 画面に出る文字（参考）
    - `mood`: 演技の方向
    - `files.<声の ID>`: 出力するファイル名

## 出力

- `voice-pack/output/` に、`lines[].files` の名前で **1つのフォルダにまとめて** 保存する
  - 例: `voice-pack/output/cute1_eacb69a7.wav`
  - 全部で `lines` の数 × `voices` の数 ファイル
- 形式: WAV、モノラル、サンプリングレート 24kHz 以上
- 前後の無音は削る（しきい値は -45dBFS くらい。言葉の頭・お尻は切らない）
- 音量はそろえる（ピーク -1dBFS くらい）
- 1セリフ4秒以内が目安。長すぎる・途中で止まる・別の言葉を言っている、ものは作り直す

## 進め方（順番に、勝手に先へ進まない）

1. **drama3-small の使い方を調べる**
   - この PC のどこに入っていて、どう呼び出すのか（Python パッケージ、CLI、ローカルサーバー、モデルのフォルダ、README やモデルカード）
   - 話者・声の指定方法（話者 ID、声の説明文、参照音声など）、演技・感情の指定方法、日本語の対応、出力のサンプリングレート、GPU が要るか
   - 推測で決めつけず、ファイルやドキュメントで確かめる。分からないことはユーザーに質問する
   - **調べた結果と「こう作ります」という案（使う話者・設定）をユーザーに報告して、OK をもらう**
2. **お試し**: 次の3セリフを男女それぞれで作り（6ファイル）、ユーザーに聞いてもらう
   - 「神作画！」（hype）、「休憩の時間です。少し休みましょう」（calm）、「100m描いた！」（hype）
   - 声や演技を調整して、ユーザーが OK を出すまで繰り返す
3. **全部作るスクリプト** `voice-pack/generate.py`（または使い方に合う言語）を作って実行する
   - すでにあるファイルは飛ばす（途中で止めても続きから再開できる）
   - 進み具合を表示し、失敗したセリフは記録して最後にまとめて報告する
   - お試しで決めた声・設定を使う
4. **確認**: 次を調べて `voice-pack/output/report.txt` にまとめる
   - `lines.json` のファイルが全部そろっているか（足りないもの・余計なもの）
   - 長さ（短すぎる・長すぎるもの）、無音・音割れのもの
   - 問題のあるものは作り直す
5. **ユーザーに、アプリへの読み込み方を伝える**（`voice-pack/README.md` の「3. アプリに読み込む」）

## 読み方のコツ

- `reading` の通りに読ませる。数字・英字（「100m」「MAX」など）を間違えて読むときは、
  読み仮名（「ひゃくメートル」「マックス」など）に直して合成してよい。**ファイル名は変えない**
- かわいい役: 明るく元気、テンション高め。渋い役: 低く落ち着いた声で、熱く短く言い切る
- `hype` はマンガのカットインらしく勢いよく、`calm` はやさしくゆっくりめに

## 守ること

- `voice-pack/lines.json` は書き換えない。ファイル名の決まり（`<声の ID>_<id>.wav`）を変えない（lines.json はアプリの `npm run voice:lines` で作り直す）
- 実在の声優・人物の声をまねる（声のクローンをする）ことはしない。参照音声を使う場合は、ユーザーが使ってよい音声だけにする
- drama3-small のライセンス（作った音声を人に配ってよいか、商用はどうか）を確認して、ユーザーに伝える
- `voice-pack/output/` の音声は Git にコミットしない（.gitignore 済み）
- 大きなパッケージのインストールや、ほかのフォルダの変更が必要なときは、先にユーザーに確認する
