# 自作の音声（drama3 などで作る読み上げ音声）

進捗ブースターのカットイン（「神作画！」「ZONE突入！！」など）を、自分の PC の音声合成で作った声で読み上げられます。
ここには、作るセリフの一覧と、手元の Claude Code に作ってもらうためのプロンプトが入っています。

| ファイル | 内容 |
| --- | --- |
| `lines.json` | 作るセリフの一覧（63 セリフ × かわいい役・渋い役 = 126 ファイル）と、ファイル名の決まり |
| `PROMPT.md` | 手元の Claude Code に渡す依頼文 |
| `output/` | 作った音声の置き場所（Git には入れません） |

## 1. 準備

- このリポジトリを PC に置く（最新版の zip を展開、または `git pull`）。`voice-pack/` フォルダがあれば OK
- drama3-small を PC に入れておく（済み）
- Claude Code（`claude` コマンド）が使えること

## 2. 手元の Claude Code に作ってもらう

1. リポジトリのフォルダ（`package.json` がある場所）でターミナルを開く
2. `claude` を起動して、次のように頼む

   ```
   voice-pack/PROMPT.md を読んで、その通りに drama3-small で音声を作ってください
   ```

3. Claude が drama3-small の使い方を調べて、声の案を出してきます。OK を出すと、3つのセリフでお試しを作るので、聞いて感想を伝えます
   （「もっと高く」「もっと叫んで」「渋さが足りない」など）
4. 気に入ったら全部作ってもらいます。`voice-pack/output/` に 126 個の WAV ができれば完成です

## 3. アプリに読み込む

1. 進捗ブースターの右上の ⚙️（設定）→「🗣️ 読み上げ」で **「自作の音声」** を選ぶ
2. **「音声ファイルを読み込む」** を押し、`voice-pack/output` フォルダを開いて、中のファイルをすべて選んで（`Ctrl + A`）「開く」
3. 「読み込み済み: かわいい役 63 / 63・渋い役 63 / 63」になれば完了。「テスト」で聞いてみてください

- 読み上げの「女性 / 渋い男性 / 交互」は、それぞれ「かわいい役 / 渋い役」の音声を使います
- 音声が無いセリフ（501本目以降の「○本突破！」など）は、ブラウザ標準の声で読みます
- 作り直したファイルを読み込むと上書きされます
- 開発版（`npm run dev`）でも、Windows アプリ版（exe）でも使えます。読み込みはそれぞれで1回ずつ必要です

## セリフを増やした・変えたとき

アプリのセリフ（`src/lib/voiceLines.ts` など）を変えたら、一覧を作り直してから、足りない分だけ作ってもらいます。

```
npm run voice:lines
```

設定の「セリフの一覧（lines.json）」ボタンからも、今のアプリに合った一覧をダウンロードできます。
