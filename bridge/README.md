# クリスタ連携ブリッジ

CLIP STUDIO PAINT（クリスタ）で線を引く・保存するたびに、進捗ブースターが反応するための常駐プログラムです。Windows 用です。

## 何を検知するか

クリスタが**前面にあるときだけ**、次の操作を検知します。

| クリスタでの操作 | 進捗ブースターでの扱い |
|---|---|
| ペン（マウスの左ボタン）で線を引く | 線1本 = +50 EXP ＋ 長さに応じたボーナス。**長さはペンが触れていた時間**で決まる（1秒 ≒ 16cm、4秒まで）。集中線が1本描かれ、「勢い」が溜まる |
| キーを続けて押す（4回以上） | セリフ入力 = 1打 +8 EXP。吹き出しが置かれ、勢いが溜まる |
| キーを1〜3回だけ押す・Ctrl などとの組み合わせ | キー操作（ショートカット）= 1回 +2 EXP。勢いが減らない |
| Ctrl + S で保存する | 1コマ完成 = +10,000 EXP。大きな演出が出る |
| Ctrl + Z でやり直す | こだわりポイント = +20 EXP。最後の集中線・吹き出しが巻き戻る |

キーボードは**押した回数だけ**を数えます。どのキーを押したか・入力した文字・描いた絵の内容は読み取らず、アプリにも送らず、どこにも記録しません。通信は PC の中（127.0.0.1）だけで、localhost で開いた進捗ブースターからの接続しか受け付けません。

## 使い方

> **大事:** ブリッジは、クリスタを使っている **Windows PC の上で** 動かす必要があります。GitHub Codespaces はクラウド上のコンピューターなので、手元の PC のペン操作は届きません。

### 初回の準備（1回だけ）

1. **Node.js をインストールします。** https://nodejs.org/ja から「LTS」版をダウンロードし、インストーラーの指示どおりに進めます。
2. **プロジェクトをダウンロードします。** 次のリンクから ZIP をダウンロードし、右クリック →「すべて展開」で展開します。
   https://github.com/kafui-133/Dojin_progress_html/archive/refs/heads/claude/nextjs-project-setup-dbddo0.zip
3. **コマンドプロンプトを開きます。** 展開したフォルダ（`package.json` が入っているフォルダ）を開き、エクスプローラー上部のアドレスバーに `cmd` と入力して Enter を押します。そのフォルダで黒い画面が開きます。
   - PowerShell だと「スクリプトの実行が無効」というエラーで `npm` が動かないことがあるため、コマンドプロンプト（cmd）を使ってください。
4. 開いた画面で次を実行します（数分かかります）。
   ```bash
   npm install
   ```

### 毎回の起動

1. 上の手順 3 と同じ方法で、プロジェクトのフォルダでコマンドプロンプトを開きます。
2. 次のコマンドで、アプリとブリッジを一緒に起動します。
   ```bash
   npm run dev:crista
   ```
3. ブラウザ（Chrome か Edge）で http://localhost:3000 を開き、「🎨 クリスタ連携」のスイッチを ON にします。
4. 画面をどこか1回クリックします。ブラウザの仕様で、一度クリックされるまで音が鳴りません。
5. 別モニターで使う場合は、ブラウザの窓を移動して、ヘッダー右端の全画面ボタンを押します。
6. クリスタで描き始めます。

終了するには、コマンドプロンプトで Ctrl + C を押します。

### 新しい版に更新するとき

ZIP をダウンロードし直して展開し、そのフォルダで `npm install` から実行してください。進捗のデータはブラウザに保存されているので、消えません。

## クリスタなしで試す

```bash
npm run dev          # ターミナル1: アプリ
npm run bridge:sim   # ターミナル2: 擬似的に線と保存を送る
```

## うまく反応しないとき

- **線を引いても反応しない:** ブリッジのターミナルに「🎨 クリスタが前面になりました」と出ているか確認してください。出ない場合は、`npm run bridge -- --any-app` で起動すると、クリスタかどうかを問わず反応します。
- **ペンタブレットで反応しない:** クリスタの［ファイル］→［環境設定］→［タブレット］で、「タブレットサービス」を Wintab と TabletPC（Windows Ink）で切り替えて試してください。
- **「ポートは使用中です」と出る:** ブリッジがすでに起動しています。前のターミナルを閉じてください。
- **クリスタを管理者として実行している:** Windows の仕様で、管理者として動いているアプリの入力は検知できません。クリスタを通常どおり起動してください。
